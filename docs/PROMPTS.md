# پرامپت‌های مکمل VBA برای پژوهشگران

## ۱) معادل لاتین برای انتقال به پانویس
```text
متن فارسی زیر را بدون تغییر معنا بررسی کن. هر اصطلاح تخصصی که معادل لاتین استاندارد و رایج دارد، فقط در اولین رخداد به شکل «اصطلاح فارسی (Latin Equivalent)» بنویس. داخل پرانتز فقط حروف لاتین، عدد و علائم ساده - / & . , : + _ ' باشد. سال ارجاع، توضیح فارسی، DOI و عبارت غیرتخصصی را وارد این الگو نکن. اگر از معادل لاتین مطمئن نیستی چیزی اضافه نکن. خروجی فقط متن اصلاح‌شده باشد.
```

## ۲) ساختارسازی تیترها
```text
ساختار مقاله را بدون تغییر متن بدنه اصلاح کن. تیتر اصلی را 1- ...، زیرتیتر را 1-1 ... و زیرزیرتیتر را 1-1-1 ... بنویس. فقط تیتر واقعی را شماره‌گذاری کن؛ جمله بدنه، فهرست، نقل‌قول و کپشن را شماره‌گذاری نکن. خروجی فقط متن کامل مقاله باشد.
```

## ۳) ممیزی ساختار فصلنامه
```text
مقاله را فقط از نظر وجود این بخش‌ها بررسی کن: مقدمه، مبانی نظری، روش تحقیق/روش‌شناسی، تجزیه و تحلیل داده‌ها و یافته‌های تحقیق، نتیجه‌گیری و پیشنهاد، فهرست منابع. چیزی را حذف یا بازنویسی نکن. جدول «بخش مورد انتظار / وجود دارد؟ / عنوان فعلی / پیشنهاد اصلاح» بده. مورد مبهم را قطعی فرض نکن.
```

## ۴) تطبیق منابع
```text
دو فهرست مستقل استخراج کن: همه ارجاع‌های درون‌متنی به ترتیب ظهور و همه منابع پایانی. نویسنده/سال را تا حد ممکن نرمال کن اما حدس نزن. فقط این سه مغایرت را گزارش کن: ارجاع بدون منبع پایانی، منبع پایانی بدون ارجاع، اختلاف مشکوک املایی/سال. منبع جدید نساز.
```

## ۵) پاک‌سازی متن AI برای Word
```text
بدون تغییر محتوا: فاصله‌های تکراری را حذف کن، نیم‌فاصله را در ترکیب‌های رایج استاندارد کن، علائم را درست فاصله‌گذاری کن و شکست خط مصنوعی وسط جمله را به پاراگراف طبیعی تبدیل کن. تیترها و شماره‌گذاری را دست نزن. خروجی فقط متن اصلاح‌شده باشد.
```
